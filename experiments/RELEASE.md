# XOPT — version 1.0.3

Version 1.0.3 follows the historical [version 1.0.2](https://doi.org/10.5281/zenodo.23627564). Version 1.0.1 remains the [original published archive](https://doi.org/10.5281/zenodo.23472314). A version-specific DOI identifies its own bytes, not a later version; the concept DOI [10.5281/zenodo.23458561](https://doi.org/10.5281/zenodo.23458561) resolves to the latest version.

The 28 October 2026 audit identified a protocol fingerprint mismatch in the published 1.0.2 correction outputs. Their original bytes and the producing protocol have been preserved separately. Version 1.0.3 adds an explicitly identified UC correction, fixed-witness radius checks and current numerical witness checks under `experiments/results/corrections_20261028/`; their outcome and source identity are established by the gate, not by this note. Historical campaign records are not reruns of the current code. The 94 historical single-coordinate interventions have separate reconstructed-witness checks; these are not the original witnesses or exact optimality certificates. Float64 and solver tolerances apply.

The standard `reproduce.sh --no-pdf` first checks the saved evidence and its fingerprints, then runs the test suites. It does not silently replace correction records or regenerate the original analyses. `--recompute` requires a new `XOPT_RESULTS_DIR` outside the historical result tree; its new attempts stay separate. See [current state](docs/current_status.md) and [the computational guide](README.md).

Version 1.0.3 is prepared from an explicit allowlist, with a separately identified projection of the retrospective provenance manifest and a recursive inspection of the released tree and archive. Editable manuscript sources and internal editorial/research material remain local. The original complete manifest stays private and is not represented as byte-identical to its public projection. Earlier commits of the public repository and versions 1.0.0 to 1.0.2 contain internal documents that version 1.0.3 excludes; publishing 1.0.3 does not remove those copies from GitHub or Zenodo.

Original code remains under MIT; data and dependencies retain their own licenses. See [license scope](LICENSING.md). Version 1.0.0 included CE4IO v1.1 under AGPL-3.0-only; later removal did not withdraw accessible copies or previously downloaded archives.
