# XOPT computational workspace — version 1.0.3

The current integration guides are the [French root README](../README.md) and [English root README](../README.en.md). Commands below run from the **repository root**, not from this directory.

The original public artifact is [version 1.0.1, Zenodo 23472314](https://doi.org/10.5281/zenodo.23472314), followed by [version 1.0.2, Zenodo 23627564](https://doi.org/10.5281/zenodo.23627564). The latter's supplied correction protocol does not match the fingerprint stored with its correction outputs. Version 1.0.3 preserves those published bytes and adds separately identified checks. See [current status](docs/current_status.md), [the 28 October addendum](docs/correction_protocol_20261028.md) and [release state](RELEASE.md).

## Standard replay

With Julia 1.11, the lockfile and Python 3.11 dependencies installed:

```bash
PYTHON_BIN="$PWD/.venv/bin/python" bash experiments/scripts/reproduce.sh --no-pdf
```

The default path first validates saved evidence and source/input fingerprints, then runs eight Julia suites and Python unit tests. It does not regenerate corrections, witnesses or analyses. A mismatch fails the gate before tests rather than replacing evidence. `--no-pdf` skips local LaTeX compilation. The 2,668 historical JSONL records are preserved.

Historical identities are in `experiments/provenance/frozen_manifest.json`, with source bytes in `experiments/provenance/objects/`. This retrospective snapshot does not repair missing original execution-time provenance. Original correction outputs remain under `corrections_20261024/`; separately bound UC, radius and witness checks are under `corrections_20261028/`. Fresh witness verification does not certify intervention minimality. The new baseline check reconstructs witnesses for 94 historical interventions; it cannot recover the original witnesses.

## New driver campaigns

```bash
XOPT_RESULTS_DIR=/tmp/xopt-recompute-20261024 XOPT_WORKERS=2 \
  PYTHON_BIN="$PWD/.venv/bin/python" \
  bash experiments/scripts/reproduce.sh --recompute --no-pdf
```

Use a new directory outside `experiments/results/`. Dependent drivers use and fingerprint new-directory inputs; the historical timing repairs are not rerun. This mode does not compute radii of new witnesses; the separately recalculated 50 radii concern historical witnesses and are not regenerated by standard replay. New statuses and counts can differ; 2,668 new records are not guaranteed. Do not move or overwrite historical records. `XOPT_WORKERS` limits concurrency (positive integer, default 2); failed children propagate an error. `JULIA_BIN` and `PYTHON_BIN` are executable paths and may contain spaces. New timing and timeout outcomes can differ from archived measurements.

The original 300-second enumeration deadline was not enforced: 41/140 UC references exceeded it, maximum 6581.36 seconds. Their observed objectives/durations remain historical evidence; corrected enumeration APIs enforce a global deadline and retain unresolved outcomes explicitly.

## Verification entry points

```bash
python3 -m unittest discover -s experiments/test -p 'test_*.py' -v
julia --startup-file=no --project=experiments experiments/test/runtests.jl
julia --startup-file=no --project=experiments experiments/test/robustness.jl
julia --startup-file=no --project=experiments experiments/test/literature_reference.jl
julia --startup-file=no --project=experiments experiments/test/anytime.jl
julia --startup-file=no --project=experiments experiments/test/levers.jl
julia --startup-file=no --project=experiments experiments/test/uc.jl
julia --startup-file=no --project=experiments experiments/test/corrections_20261024.jl
julia --startup-file=no --project=experiments experiments/test/coordinate_cost_regression.jl
```

The root workflow validates the supplied correction files before running the tests. Generating a new separately identified correction or fresh witness report is a distinct operation described in the addendum; an individual passing suite is narrower evidence.

The UC analysis preserves the original 139/140 agreements and adds one identified correction to reach an effective 140/140; it does not claim a new 140-case campaign. Original weak radii equal to zero are observations about tied witnesses, not a theorem about every weak explanation. Computation remains Float64/tolerance based.
